홈페이지형 블로그 위젯 메이커

링크만 넣으면 위젯 코드 5개가 자동으로 완성됩니다. 코딩 몰라도 괜찮아요.

① 템플릿② 내 정보③ 버튼·링크④ 코드 받기⑤ 블로그에 붙이기⑥ AI 소개글
STEP 1

템플릿 고르기

마음에 드는 디자인 하나를 고르세요. 버튼 위치가 템플릿마다 달라서, 여기서 고른 것과 캔바에서 쓰는 것이 같아야 합니다.

캔바 템플릿 열기 ↗ 캔바에서 [템플릿 사용] → 내 정보로 글자·사진 바꾸기 → PNG로 저장
STEP 2

내 정보 정리

캔바 디자인에 들어갈 글과, AI 소개글(STEP 6)에 쓰일 정보입니다. 적어 두면 이 컴퓨터에 자동 저장됩니다.

STEP 3

버튼 이름과 링크 넣기

배너 아래 버튼 5개에 무엇을 연결할지 정하고, 주소를 붙여 넣으세요. 버튼은 왼쪽부터 1번입니다.

링크는 어디서 복사하나요?
· 카테고리(게시판): 내 블로그에서 카테고리를 누른 뒤, 주소창의 주소를 복사하거나 아래 도우미로 만드세요.
· 특정 글(소개글·오시는 길 등): 글을 연 뒤 주소창 주소 복사 (예: https://blog.naver.com/아이디/224…)
· 바깥 링크(인스타·카카오채널·예약·스마트스토어 등): 그 페이지의 주소를 그대로 붙여 넣으세요.
카테고리 링크 만들기 도우미

블로그 관리 → 메뉴·글·동영상 관리 → 블로그(카테고리)에서 카테고리를 누르면 오른쪽에 카테고리 번호가 보입니다. 또는 카테고리를 눌렀을 때 주소 끝의 categoryNo= 뒤 숫자입니다.


    

  


  

  






  STEP 4
  
위젯 코드 받기

  
입력하면 바로 완성됩니다. 1번부터 5번까지 차례대로 복사해서 블로그에 붙이세요.

  

    미리보기에서 눌러 보세요. 파란 칸 = 블로그 홈 · 연두 칸 = 버튼 · 초록 칸 = SNS. 빨간 점선 칸은 아직 링크가 비어 있습니다.
    같은 블로그 안의 링크는 지금 창에서, 바깥 링크는 새 창으로 열리게 자동으로 맞춰 둡니다.
  

  

  

    
    
    
  

  

  

    (선택) 투명 이미지를 내 블로그 것으로 바꾸기
    
코드에는 기본으로 강의용 투명 이미지(170×600)가 들어 있습니다. 그대로 써도 됩니다. 내 블로그에 올린 이미지로 바꾸고 싶다면:

    
    
      
  1. 투명 이미지 내려받기 (170×600 PNG)
    2. 
      
  2. 내 블로그에 새 글을 쓰고 이 이미지를 올린 뒤 비공개로 발행
    3. 
      
  3. 올라간 이미지를 마우스 오른쪽 클릭 → 이미지 주소 복사
    4. 
      
  4. 아래 칸에 붙여 넣기 (https:// 로 시작)
    5. 
    

    
    

  






  STEP 5
  
블로그에 붙이기

  
PC에서 진행하세요. 처음 한 번만 순서대로 하면 됩니다.

  
① 레이아웃 정하기

  
    
    
  1. 내 블로그 → 프로필 아래 관리 → 꾸미기 설정 → 레이아웃·위젯 설정
    2. 
    
  2. 레이아웃은 위쪽에 넓은 칸이 있는 형태(메뉴 위·글 영역 위 상단형)를 고르기
    3. 
    
  3. 오른쪽 아래 타이틀 체크를 해제 (블로그 이름 글자가 배너를 가리지 않도록)
    4. 
  

  
② 위젯 코드 5개 등록

  
    
    
  1. 같은 화면 오른쪽 아래 + 위젯직접등록 클릭
    2. 
    
  2. 위젯명: 1 / 코드: STEP 4의 1번 코드 붙여넣기 → 다음 → 등록
    3. 
    
  3. 같은 방법으로 2, 3, 4, 5번까지 등록
    4. 
    
  4. 위젯 5개를 마우스로 끌어 상단 칸에 1→5 순서로 가로로 나란히 놓기
    5. 
    
  5. 맨 아래 적용
    6. 
  

  
③ 배너(스킨) 이미지 올리기

  
    
    
  1. 관리 → 꾸미기 설정 → 세부 디자인 설정
    2. 
    
  2. 왼쪽 스킨배경 → 직접등록 → 상단 영역에 캔바에서 저장한 PNG 올리기
    3. 
    
  3. 적용
    4.
